# ABI Brand Guidelines

## 1. Purpose of the Brand Guide

The ABI Brand Guide is used to keep the brand consistent across different materials and platforms.

Important reminders:
- Follow the official brand rules when creating ABI materials.
- Brand materials should only be used with proper permission.
- If something is outside the guide, ask for approval first.
- The guide is meant to help people create outputs that still clearly look and feel like ABI.

- Use "team" instead of "family" for the workplace.
- Do not openly attack or criticize competitors.
- Avoid political commentary.
- Avoid too much technical jargon.
- Explain technical terms when necessary.

  - Cost-effective
  - Fit your budget
  - Value for money

## 21. Logo Versions

Approved versions include:
- Horizontal lockup
- Vertical lockup
- Icon with name
- Icon-only

General rules:
- Horizontal lockup is preferred when possible.
- Vertical lockup works well for tall or centered layouts.
- Icon-only can be used when the ABI name is still clearly visible nearby.
- Always choose the version that is easiest to read.

## 22. Logo Placement

### Horizontal Logo
Can be placed:
- In corners
- In the center

### Vertical Logo
Best placed:
- In the center

Avoid placing the vertical logo in corners.

### Icon Lockups
Can be placed:
- Sides
- Corners
- Center

## 23. Logo Clear Space

Keep enough empty space around the logo.

Minimum clear space:
- Equal to the height of the ABI icon on all four sides.

This helps keep the logo readable and visible.

## 24. Logo Rules and Common Errors

Do not:
- Stretch the logo
- Squash the logo
- Skew the logo
- Distort the logo
- Change the logo colors
- Lower its opacity
- Add shadows
- Change the arrangement of logo parts
- Place it on a busy background
- Remove the required clear space

## 25. Social Media Logo Use

For social media avatars:
- Use the icon-only version.
- Keep proper clear space.
- The icon should ideally use around 65% of the image area.
- Approved secondary colors may be used for special events or seasonal content.

## 27. Color Usage Rules

- Primary and base colors should be used for backgrounds.
- Orange should mainly be used as an accent.
- Orange should not be used as the main background color.
- Use approved colors only.
- Maintain good text contrast.
- Avoid teal text on very light backgrounds.
- Use 20% tint steps if color tints are needed.

Preferred:

- Archivo Regular for body text

## 29. Typography Rules

The guide lists six important typography rules:

1. Stay left-aligned and rag right.
2. Use strong size and weight contrast.
3. Align x-heights or baselines.
4. Watch the ragged edge of paragraphs.
5. Give elements enough space.
6. Keep line length reasonable.

Recommended line length:
- Around 45 to 70 characters

## 30. Typography Common Errors

Do not:
- Stretch or distort text
- Use unauthorized fonts
- Add outlines or strokes
- Add drop shadows
- Use extreme spacing
- Rotate text at random angles
- Use centered alignment for multi-line body text
- Fully justify multi-line text

Typography should normally be at:
- 0 degrees
- 90 degrees if needed

## 32. Visual Style Usage

Key visuals can be used for:
- Framing content
- Filling negative space
- Adding background visual interest

Important:
- Keep visuals subtle when content is the main focus.
- Avoid using too many key visuals.
- Do not make layouts look crowded.

## 33. Accessibility

All outputs should remain easy to read.

Important:
- Use good contrast.
- Avoid white text on very light backgrounds.
- Avoid black text on very dark backgrounds.
- Do not use colors in ways that reduce readability.

## 34. Approval Rules

Any brand execution should follow the official guide.

If something is outside the guidelines:
- Ask an authorized ABI representative.
- Get approval before publishing, printing, or using it.

For vendor materials:
- Proofs should be reviewed before final production.

## 35. File Types

### Raster Files
Examples:
- JPG
- PNG
- GIF
- PSD

Best for:
- Photos
- Digital/web graphics

Important:
- Raster files can lose quality when enlarged.
- Print files should generally be at least 150 DPI.

### Vector Files
Examples:
- AI
- EPS
- SVG

Best for:
- Logos
- Icons
- Illustrations
- Print materials

Important:
- Vector files can scale without losing quality.
- Use vector files when a high-resolution logo is needed.
