# ABI Internship Day 1 Notes

## 1. Technical and Admin Setup

- GitHub was mentioned for technical work.
- Admin access is needed when working with data.
- Naming conventions are important to keep files and projects organized.

## 2. Marketing and Tech Collaboration

- Marketing and Technical teams work together.
- Communication and branding should be aligned with technical work.
- Technical information should be explained in simple words so non-technical teams can understand it.

## 3. Google Analytics and WordPress

- Google Analytics helps track website activity and user behavior.
- WordPress is used to manage and publish website content.
- Data from different tools can be combined to get a better view of website performance.

## 4. Ahrefs

- Ahrefs is used for SEO and website progress tracking.
- It can help check:
  - Keywords
  - Rankings
  - Backlinks
  - Organic traffic
- Website activity may also connect with:
  - Social media
  - CRM
  - EDM

## 5. GitHub and Brand Guidelines

- GitHub can be used to organize and manage technical files.
- Brand guidelines should be followed when creating technical or visual outputs.
- Important brand details include:
  - Colors
  - Fonts
  - Logo usage
  - Tone and style

## 6. Gamma

- Gamma can be used to create presentations and documentation.
- It may connect with:
  - Google Sheets
  - Project management tools
  - Project data
- It helps turn data into easy-to-understand presentations.

## 7. Project Progress and Engineering Data

- Project progress should not always be calculated using a simple average.
- Different engineering tasks may have different weights or importance.
- Engineers should be asked to calculate project accomplishment properly.
- This helps avoid showing incorrect or misleading progress.

## 8. Make - Automation

- Make is used for automation.
- It can connect different systems and move data automatically.
- It can help reduce repetitive manual work.

## 9. CJM

- CJM means Customer Journey Map.
- It helps understand the steps a customer goes through.
- It can also show customer touchpoints and possible problems.

## 10. Google Search Console

- Google Search Console helps track website performance in Google Search.
- Important data includes:
  - Impressions
  - Clicks
  - CTR
  - Search position
